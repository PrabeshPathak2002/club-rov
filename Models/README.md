# Interactive assembly preview

[Open the detailed STL in GitHub's 3D viewer](club-rov-preview.stl). Drag to rotate, right-drag to pan, and scroll to zoom.

The root README embeds a reduced-detail ASCII STL for an inline interactive preview, omitting the detailed enclosure flanges to keep the page lightweight. The separate binary STL includes those flanges, preserves more detail, and stays below GitHub's 10 MB viewer limit. STL is monochrome; the accompanying Fusion screenshot shows the design colors.

Exported from the active Future ROV Fusion assembly on 29 September 2026. Includes the enclosure, six thrusters, frame, clamps, and handle. Internal electronics, liners, and fasteners are omitted. The README mesh is heavily simplified and may soften or remove small details. Neither mesh is a printable assembly or a manufacturing reference; use the original individual print parts for fabrication.

The assembly includes imported enclosure and APISQUEEN U01 reference geometry alongside the custom frame and mounts. No new ownership or reuse license is asserted over third-party designs. See [publishing and attribution](../Documentation/PUBLISHING.md).
