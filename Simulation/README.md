# ROV simulation

[ClubROVSim](ClubROVSim/README.md) is my Unity pool-training prototype. Open that folder in Unity Hub and use Unity 6000.6.7f1.

It includes the assembly visual, six independent thruster forces, buoyancy and drag, keyboard/gamepad input, chase/onboard cameras and a telemetry HUD. Physics values are provisional; the prototype has no connection to the physical vehicle or autopilot yet.
